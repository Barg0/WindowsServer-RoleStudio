# Installation media

Park ISOs here — the Exchange Server SE ISO above all. The console picker opens in
this folder when it holds at least one `.iso`, and the default config path is
`isos\ExchangeServer*.iso`, so a CU bump needs no config edit: the newest match wins.

Nothing in this folder is committed: an ISO is gigabytes of somebody else's
licensed media, and `.gitignore` excludes everything here except this file.
